# Zerdeli Results — Netlify

Сайт результатов олимпиады. Данные берутся напрямую из Google Таблицы, лист «Нәтижелер». Базы данных нет.

## 1. Таблица
- Лист «Нәтижелер», первая строка — заголовки. Сайт понимает текущую структуру:
  Облыс | Аудан | Мектеп | Сынып | Литер | Оқушы аты-жөні | Оқу тілі | Мұғалім | Балл-1 | Балл-2 | Балл-3 | Жалпы балл | Орын | Келесі кезеңге өтті | Қатысты | studentId
  Порядок колонок можно менять, колонки распознаются по названию.
- Класс на сайте = Сынып + Литер («3 «А»»). «Орын» (I/II/III орын) показывается медалью. «Қатысты: Жоқ» → «қатыспады».
- Доступ к таблице: **Настройки доступа → Все, у кого есть ссылка → Читатель**.
- Статус «Келесі кезеңге өтті»: Иә / Да / Өтті → прошёл; Жоқ / Нет / Өтпеді → не прошёл; пусто → «результат позже».
- Изменения в таблице появляются на сайте примерно через минуту. Передеплой не нужен.

## 2. Деплой (только через Netlify CLI — перетаскивание папки не загружает функцию)
```
cd zr-netlify
netlify deploy --prod
```
При первом запуске выберите «Create & configure a new site».

## 3. Кабинет
`https://ВАШ-САЙТ.netlify.app/admin` — обзор, проверка таблицы на ошибки, поиск ученика, генератор настроек.

## Настройки (необязательно)
Лист «Баптаулар» в той же таблице. Его содержимое собирается во вкладке «Настройки сайта» кабинета — скопировать и вставить в A1.
Без этого листа сайт работает с настройками по умолчанию.

## Другая таблица
Переменные окружения в Netlify: `SHEET_ID`, `SHEET_NAME` (по умолчанию «Нәтижелер»).
